# @typescript-on-rails/web

Host-neutral HTTP contracts and the official Next and React bindings. `bindRoute` derives method, path, validation, authorization, and execution from one core route while keeping request scope and response formatting explicit. `nextRouteFor` resolves that exact registered binding from the application graph. The package also owns bounded request decoding, safe errors, cache policy, secure headers, cookies, trusted-origin and CSRF checks, and React streaming.

It does not choose an identity provider or application permission policy.
